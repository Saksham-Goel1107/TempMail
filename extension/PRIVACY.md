# TempMail Pro - Privacy Policy

**Last Updated**: October 22, 2025

## Introduction

TempMail Pro ("we", "our", or "the extension") is committed to protecting your privacy. This privacy policy explains how our browser extension handles data.

## Data Collection

**We DO NOT collect, store, or transmit any personal data.**

### What We Don't Collect:
- Personal information
- Browsing history
- Email content
- Usage analytics
- Tracking data
- Cookies
- IP addresses
- Location data

## Data Storage

All data generated by the extension is stored **locally on your device** using your browser's local storage API. This includes:

- Temporary email address
- Authentication token
- Received messages

**Important**: This data never leaves your device except when communicating with the TempMail API to generate emails and fetch messages.

## Third-Party Services

The extension communicates with the TempMail API (https://pro-tempmail.onrender.com) to:
1. Generate temporary email addresses
2. Fetch received messages

The API follows its own privacy policy and does not store emails permanently. All temporary emails are automatically deleted after a certain period.

## Permissions Explained

The extension requires the following permissions:

### Storage Permission
- **Purpose**: Save your temporary email and messages locally on your device
- **Scope**: Browser local storage only
- **Data**: Email address, token, and messages

### Active Tab Permission
- **Purpose**: Auto-fill email addresses on web pages you visit
- **Scope**: Only when you explicitly use the fill feature
- **Data**: No data is collected; only used to inject the email

### Scripting Permission
- **Purpose**: Enable the content script to detect email input fields
- **Scope**: All websites (to detect email fields)
- **Data**: No data is collected or transmitted

### Host Permissions
- **Purpose**: Connect to the TempMail API
- **Scope**: Only https://pro-tempmail.onrender.com
- **Data**: Email address and authentication token

## Data Security

- All API communications use HTTPS encryption
- Data stored locally is protected by your browser's security
- No cloud storage or external databases
- HTML content in emails is sanitized to prevent XSS attacks

## Your Rights

You have full control over your data:

- **Access**: All data is visible in the extension
- **Delete**: Remove the extension to delete all local data
- **Export**: Use browser developer tools to access stored data
- **Control**: Generate new emails or clear messages anytime

## Children's Privacy

The extension does not knowingly collect data from anyone, including children under 13. No registration or personal information is required to use the extension.

## Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected in the extension's listing on the respective browser stores.

This extension is designed with privacy as the core principle:
- Open source (code available for review)
- No telemetry or analytics

## Data Retention

- **Local Storage**: Data persists until you clear browser data or uninstall the extension
- **API Server**: Temporary emails expire automatically according to the mail.tm service policy
- **Messages**: Stored locally until you generate a new email or uninstall

## Third-Party Access

We do not sell, trade, or transfer your data to third parties. The extension only communicates with:
1. **TempMail API** (https://pro-tempmail.onrender.com) - For email generation and message retrieval
2. **mail.tm API** (backend service) - For temporary email functionality

## Compliance

This extension complies with:
- General Data Protection Regulation (GDPR)
- California Consumer Privacy Act (CCPA)
- Browser extension privacy policies (Chrome, Firefox, Edge)

## Your Consent

By using the extension, you consent to this privacy policy.

## How to Delete Your Data

To completely remove all data:
1. Remove/uninstall the extension from your browser
2. Clear browser local storage (optional)

All data associated with the extension will be permanently deleted from your device.
